# Malay + Mandarin i18n Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Malay (`/ms/`) and Mandarin/Simplified Chinese (`/zh/`) versions of all 56 real pages on greatermalaysia.com, with correct hreflang/canonical/sitemap wiring, so the site is a proper three-language property for search and answer engines by tomorrow's staging push.

**Architecture:** Same-slug subdirectory structure (`/road-tax`, `/ms/road-tax`, `/zh/road-tax`) on one domain. A small set of Node scripts mechanically generate the ms/zh HTML skeletons (correct `lang`, hreflang, canonical, internal links, nav/footer boilerplate) from the English source; translation agents then fill in the page-specific prose inside each skeleton. A tiny runtime `i18n.js` string table covers the handful of JS-generated UI strings. No build step / templating engine is introduced — the site stays static files, now 168 instead of 56.

**Tech Stack:** Plain Node.js (>=18, ESM, `"type": "module"` already set in `package.json`), no new dependencies. Tests use Node's built-in `node:test` + `node:assert/strict` (no test framework currently in this repo — this is the first).

## Global Constraints

- Every translated page needs: `lang` attribute, self-referential canonical, hreflang alternates to all 3 versions + `x-default`, translated title/meta description/OG/Twitter tags, translated JSON-LD (`inLanguage` + text fields), translated visible content — per [2026-07-13-ms-zh-i18n-design.md](../specs/2026-07-13-ms-zh-i18n-design.md).
- Slugs are identical across languages — no translated URL slugs.
- `/ms/` = Malay, `/zh/` = Simplified Chinese (`zh-Hans`) — not Traditional.
- hreflang values: `en-MY`, `ms-MY`, `zh-Hans-MY`, `x-default` → English root.
- `og:locale` values: `en_MY`, `ms_MY`, `zh_CN` (Facebook's supported-locale list has no `zh_MY`; `zh_CN` is the correct Simplified-Chinese OG value — hreflang carries the MY-specificity instead). Only 1 of the 56 English source pages (`index.html`) actually declares `og:locale` today — `setLangAttrs` (Task 3) replaces it where present and is a no-op where it's absent, matching English rather than inventing a tag English itself doesn't have. Not a regression: hreflang, not og:locale, is the tag search/answer engines actually key off for language variants.
- No auto-redirect by `Accept-Language` or geo-IP — manual switcher only.
- Excluded from all i18n work (gitignored + vercelignored operator tooling): `posting-kit.html`, `assets/sharecard-*.html`, `assets/daily/*.html`, `data/daily-cards.json`.
- Number formatting (`fmt()` in `common.js`, `en-MY` locale) stays unchanged in all three languages — this is correct Malaysian digit formatting, not an English-ism.
- Known accepted risk: AI-translated content, no native-speaker review gate before staging. `stamp-duty`, `road-tax`, `take-home-pay`, `government-tender-malaysia`, `how-to-check-voter-registration` are the highest-risk pages for terminology precision.

## File Structure

New:
- `scripts/i18n/manifest.mjs` — canonical list of all 56 pages (slug, source file, sitemap metadata) + the 3 language configs. Single source of truth every other script imports.
- `scripts/i18n/manifest.test.mjs` — sanity tests on the manifest (count, uniqueness, required fields).
- `scripts/i18n/glossary.mjs` — fixed EN/MS/ZH strings for nav, footer boilerplate, and the language switcher. Reused verbatim on all 168 files so this boilerplate is 100% consistent.
- `scripts/i18n/glossary.test.mjs` — key-parity test (every EN key has an MS and ZH value).
- `scripts/i18n/localize.mjs` — pure HTML-string transforms: `injectHreflang`, `insertLangSwitcher`, `rewriteInternalLinks`, `setLangAttrs`, `applyNavFooterGlossary`, and `localizePage` (composes all of them for ms/zh generation).
- `scripts/i18n/localize.test.mjs` — unit tests for each transform against fixture HTML snippets.
- `scripts/gen-locale-pages.mjs` — CLI: writes the 112 `ms/`/`zh/` skeleton files from the English sources via `localizePage`.
- `scripts/update-en-hreflang.mjs` — CLI: idempotently inserts the hreflang block + language switcher into the 56 existing English files in place.
- `scripts/verify-i18n.mjs` — CLI + importable `verifyPage(html, expectations)`: structural checks (lang attr, 4 hreflang links, canonical, og:locale, JSON-LD `inLanguage`, internal links correctly prefixed, no leftover English glossary boilerplate on translated pages). Used both as an automated gate after each script run and per translation batch.
- `scripts/gen-sitemap-i18n.mjs` — CLI: regenerates `sitemap.xml` with `xhtml:link hreflang` annotations from the manifest.
- `assets/i18n.js` — runtime string table (`STRINGS`) + `t(key, vars)` helper for the ~12 JS-generated UI strings.
- 112 new HTML files under `ms/` and `zh/`, mirroring root, `election/`, `explainers/`, `stories/`, `waktu-solat/`.

Modified:
- 56 existing English HTML files — hreflang block + language switcher inserted (via script, not by hand).
- `common.js`, `app.js`, `answer.js` — swap ~12 hardcoded runtime strings for `t()` calls; add `<script src="/assets/i18n.js">` before `common.js` on all 168 pages (via script).
- `styles.css` — add `.nav-lang` switcher styles.
- `sitemap.xml` — regenerated with hreflang annotations, now 168 URL entries.
- `llms.txt` — one added line pointing to `/ms/` and `/zh/`.

```js
// scripts/i18n/localize.mjs
import { PAGES, LANGS, SITE_ORIGIN } from "./manifest.mjs";
import { GLOSSARY } from "./glossary.mjs";

export function pageSlugSet() {
  return new Set(PAGES.map((p) => p.slug));
}

function escapeRegExp(s) {
  return s.replace(/[.*+?^${}()|[\]\\]/g, "\\$&");
}

// Rewrites a single URL/path string to its language-prefixed form, if (and
// only if) it points at a known page slug. Shared assets, external links,
// and the JSON-LD org/site identity anchors (#org, #site) are left alone.
export function rewriteUrl(raw, prefix, slugSet) {
  if (!prefix) return raw; // English is unprefixed — never rewrite
  const domainMatch = raw.match(/^(https:\/\/greatermalaysia\.com)(\/.*)?$/);
  let domain = "";
  let rest = raw;
  if (domainMatch) {
    domain = domainMatch[1];
    rest = domainMatch[2] || "/";
  } else if (!raw.startsWith("/")) {
    return raw; // external URL (https://x.com/..., mailto:, etc.)
  }
  const hashIndex = rest.indexOf("#");
  const withoutHash = hashIndex === -1 ? rest : rest.slice(0, hashIndex);
  const base = withoutHash.split("?")[0];
  const fragment = hashIndex === -1 ? "" : rest.slice(hashIndex);
  if (fragment === "#org" || fragment === "#site") return raw;
  if (!slugSet.has(base)) return raw;
  return `${domain}${prefix}${rest}`;
}

// Rewrites every href="", src="", content="" attribute and every JSON-LD
// "url":"..." / "@id":"..." field that points at a known internal page.
export function rewriteInternalLinks(html, { prefix, slugSet }) {
  if (!prefix) return html;
  let out = html.replace(/(href|src|content)="([^"]*)"/g, (m, attr, val) => `${attr}="${rewriteUrl(val, prefix, slugSet)}"`);
  out = out.replace(/"(url|@id)":"([^"]*)"/g, (m, key, val) => `"${key}":"${rewriteUrl(val, prefix, slugSet)}"`);
  return out;
}

// Inserts hreflang alternate links (en/ms/zh + x-default) immediately after
// the page's <link rel="canonical"> tag.
export function injectHreflang(html, { slug }) {
  const canonicalRe = /(<link rel="canonical" href="[^"]+"\s*\/>)/;
  if (!canonicalRe.test(html)) throw new Error("injectHreflang: canonical link not found");
  const alt = ["en", "ms", "zh"]
    .map((code) => `<link rel="alternate" hreflang="${LANGS[code].hreflang}" href="${SITE_ORIGIN}${LANGS[code].prefix}${slug}" />`)
    .join("");
  const xdefault = `<link rel="alternate" hreflang="x-default" href="${SITE_ORIGIN}${slug}" />`;
  return html.replace(canonicalRe, `$1${alt}${xdefault}`);
}

// Inserts the EN / BM / 中文 language switcher between the "Follow the
// channel" nav CTA and the mobile burger button. Matches structurally (not
// on the CTA's href value) so it works whether or not rewriteInternalLinks
// has already run.
export function insertLangSwitcher(html, { slug, currentLangCode }) {
  const anchorRe = /(<\/nav>\s*<a class="nav-cta"[^>]*>Follow the channel<\/a>\s*)(<button class="nav-burger")/;
  if (!anchorRe.test(html)) throw new Error("insertLangSwitcher: nav CTA anchor not found");
  const items = ["en", "ms", "zh"]
    .map((code) => {
      const lang = LANGS[code];
      const href = `${lang.prefix}${slug}`;
      const current = code === currentLangCode ? ' class="is-current" aria-current="true"' : "";
      return `<a href="${href}"${current}>${lang.label}</a>`;
    })
    .join("");
  const block = `<div class="nav-lang" aria-label="Language">${items}</div>`;
  return html.replace(anchorRe, `$1${block}$2`);
}

// Translates every fixed nav/footer boilerplate text node using GLOSSARY.
// Every key except footFollowPrefix is matched as a whole `>text<` node;
// footFollowPrefix matches the `>text<a` prefix before the WhatsApp link
// since that footer line is split across anchor tags in the real markup.
export function applyNavFooterGlossary(html, { langCode }) {
  let out = html;
  for (const [key, entry] of Object.entries(GLOSSARY)) {
    const target = entry[langCode];
    if (key === "footFollowPrefix") {
      out = out.replace(new RegExp(`>${escapeRegExp(entry.en)}<a`, "g"), `>${target}<a`);
      continue;
    }
    out = out.replace(new RegExp(`>${escapeRegExp(entry.en)}<`, "g"), `>${target}<`);
  }
  return out;
}

// Sets <html lang="..."> and the og:locale meta value.
export function setLangAttrs(html, { langCode }) {
  const lang = LANGS[langCode];
  let out = html.replace(/<html lang="en">/, `<html lang="${lang.htmlLang}">`);
  out = out.replace(/(og:locale" content=")en_MY(")/, `$1${lang.ogLocale}$2`);
  return out;
}

// Composes every mechanical transform, in the one order that's safe:
// 1. rewrite existing links while nav/footer text is still English
// 2. insert the switcher (structural match, unaffected by step 1)
// 3. translate nav/footer boilerplate (after the switcher anchor is used)
// 4. inject hreflang (independent of all of the above, computed from slug)
// 5. set <html lang> + og:locale
export function localizePage(html, { langCode, slug }) {
  const prefix = LANGS[langCode].prefix;
  let out = rewriteInternalLinks(html, { prefix, slugSet: pageSlugSet() });
  out = insertLangSwitcher(out, { slug, currentLangCode: langCode });
  out = applyNavFooterGlossary(out, { langCode });
  out = injectHreflang(out, { slug });
  out = setLangAttrs(out, { langCode });
  return out;
}
```

```js
// scripts/verify-i18n.mjs
import { readFileSync } from "node:fs";
import { PAGES, LANGS, SITE_ORIGIN } from "./i18n/manifest.mjs";
import { GLOSSARY } from "./i18n/glossary.mjs";

export function verifyPage(html, { langCode, slug }) {
  const problems = [];
  const lang = LANGS[langCode];

  if (!html.includes(`<html lang="${lang.htmlLang}">`)) {
    problems.push(`missing <html lang="${lang.htmlLang}">`);
  }

  const hreflangCount = (html.match(/hreflang=/g) || []).length;
  if (hreflangCount !== 4) problems.push(`expected 4 hreflang links, found ${hreflangCount}`);

  const expectedCanonical = `${SITE_ORIGIN}${lang.prefix}${slug}`;
  if (!html.includes(`<link rel="canonical" href="${expectedCanonical}"`)) {
    problems.push(`canonical is not self-referential (expected ${expectedCanonical})`);
  }

  if (langCode !== "en") {
    for (const [key, entry] of Object.entries(GLOSSARY)) {
      if (key === "footFollowPrefix") continue; // not present on every page, checked separately if needed
      if (entry.en === entry[langCode]) continue; // e.g. "Waktu solat" is identical in en/ms
      if (html.includes(`>${entry.en}<`)) {
        problems.push(`leftover untranslated glossary string "${entry.en}" (key ${key})`);
      }
    }
    if (/"inLanguage":\s*"en-MY"/.test(html)) {
      problems.push("JSON-LD inLanguage still says en-MY");
    }
  }

  return problems;
}

export function resolveLangAndSlug(filePath) {
  for (const code of ["ms", "zh"]) {
    const prefix = code + "/";
    if (filePath.startsWith(prefix)) {
      const rest = filePath.slice(prefix.length);
      const page = PAGES.find((p) => p.file === rest);
      if (!page) throw new Error(`resolveLangAndSlug: no manifest entry for ${rest}`);
      return { langCode: code, slug: page.slug };
    }
  }
  const page = PAGES.find((p) => p.file === filePath);
  if (!page) throw new Error(`resolveLangAndSlug: no manifest entry for ${filePath}`);
  return { langCode: "en", slug: page.slug };
}

const isMain = process.argv[1] && import.meta.url === `file://${process.argv[1]}`;
if (isMain) {
  const files = process.argv.slice(2);
  if (files.length === 0) {
    console.error("Usage: node scripts/verify-i18n.mjs <file1> <file2> ...");
    process.exit(1);
  }
  let failCount = 0;
  for (const filePath of files) {
    const { langCode, slug } = resolveLangAndSlug(filePath);
    const html = readFileSync(filePath, "utf8");
    const problems = verifyPage(html, { langCode, slug });
    if (problems.length) {
      failCount++;
      console.log(`FAIL ${filePath}`);
      for (const p of problems) console.log(`  - ${p}`);
    } else {
      console.log(`PASS ${filePath}`);
    }
  }
  process.exit(failCount ? 1 : 0);
}
```

## Task 14: Regenerate `sitemap.xml` with hreflang annotations

**Files:**
- Create: `scripts/gen-sitemap-i18n.mjs`
- Modify (as output, not by hand): `sitemap.xml`

**Interfaces:**
- Consumes: `PAGES`, `LANGS`, `SITE_ORIGIN` from `scripts/i18n/manifest.mjs` (Task 1).
- Produces: nothing importable — one-shot CLI, output is `sitemap.xml` itself.

`sitemap.xml` currently has 55 plain `<url>` entries (no `for-agents.html`, no i18n). This regenerates it as a proper multilingual sitemap: one `<url>` block per language per page (168 total = 56 × 3), each annotated with `xhtml:link hreflang` alternates to its two siblings + `x-default`, per Google's documented format for this case.

- [ ] **Step 1: Write the script**

```js
// scripts/gen-sitemap-i18n.mjs
import { writeFileSync } from "node:fs";
import { fileURLToPath } from "node:url";
import { PAGES, LANGS, SITE_ORIGIN } from "./i18n/manifest.mjs";

function altLinks(page) {
  const alternates = ["en", "ms", "zh"]
    .map((code) => `<xhtml:link rel="alternate" hreflang="${LANGS[code].hreflang}" href="${SITE_ORIGIN}${LANGS[code].prefix}${page.slug}"/>`)
    .join("");
  const xdefault = `<xhtml:link rel="alternate" hreflang="x-default" href="${SITE_ORIGIN}${page.slug}"/>`;
  return alternates + xdefault;
}

function urlEntry(page, langCode) {
  const lang = LANGS[langCode];
  const loc = `${SITE_ORIGIN}${lang.prefix}${page.slug}`;
  return `<url><loc>${loc}</loc>${altLinks(page)}<lastmod>${page.lastmod}</lastmod><changefreq>${page.changefreq}</changefreq><priority>${page.priority}</priority></url>`;
}

const urls = PAGES.flatMap((page) => ["en", "ms", "zh"].map((code) => urlEntry(page, code))).join("\n  ");

const xml = `<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9" xmlns:xhtml="http://www.w3.org/1999/xhtml">
  ${urls}
</urlset>
`;

const ROOT = fileURLToPath(new URL("..", import.meta.url)); // fileURLToPath, not .pathname — project path has spaces
writeFileSync(`${ROOT}sitemap.xml`, xml);
console.log(`Wrote sitemap.xml with ${PAGES.length * 3} URL entries.`);
```

## Task 16: Full-site verification pass

**Files:**
- Create: `scripts/check-broken-links.mjs`

**Interfaces:**
- Consumes: `PAGES` from `scripts/i18n/manifest.mjs` (Task 1); `pageSlugSet` from `scripts/i18n/localize.mjs` (Task 3); `verifyPage`/`resolveLangAndSlug` from `scripts/verify-i18n.mjs` (Task 6).

This is the final gate before the branch is ready for its staging push: every page passes structural verification (Task 6's checks, individually confirmed per-batch in Tasks 9–13 but not yet run as one combined pass) and no page links to a slug that doesn't exist anywhere in the manifest.

- [ ] **Step 1: Write the broken-link checker**

```js
// scripts/check-broken-links.mjs
import { readFileSync } from "node:fs";
import { fileURLToPath } from "node:url";
import { PAGES } from "./i18n/manifest.mjs";
import { pageSlugSet } from "./i18n/localize.mjs";

const ROOT = fileURLToPath(new URL("..", import.meta.url)); // fileURLToPath, not .pathname — project path has spaces
const slugs = pageSlugSet();
const NON_PAGE_RE = /^\/(assets|data)\/|\.(css|js|txt|xml|json|ico|png)$/;

let problems = [];
for (const page of PAGES) {
  for (const prefix of ["", "ms/", "zh/"]) {
    const filePath = `${ROOT}${prefix}${page.file}`;
    const html = readFileSync(filePath, "utf8");
    const hrefs = [...html.matchAll(/(?:href|src)="(\/[^"]*)"/g)].map((m) => m[1]);
    for (const raw of hrefs) {
      const base = raw.split(/[?#]/)[0];
      if (NON_PAGE_RE.test(base)) continue;
      let bare = base;
      for (const p of ["/ms", "/zh"]) {
        if (base === p || base.startsWith(p + "/")) { bare = base.slice(p.length) || "/"; break; }
      }
      if (!slugs.has(bare)) problems.push(`${prefix}${page.file}: links to unknown page "${raw}"`);
    }
  }
}
if (problems.length) {
  console.log(`${problems.length} links to unknown pages:`);
  problems.forEach((p) => console.log(`  ${p}`));
  process.exit(1);
} else {
  console.log(`No broken internal links found across ${PAGES.length * 3} pages.`);
}
```
