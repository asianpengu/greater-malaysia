面向 AI 代理与开发者

马来西亚权威数据,为机器而生

Greater Malaysia 是面向 AI 代理、值得信赖且注明来源的数据层,专为需要马来西亚实时事实的代理而建。提供免费的 REST API 与 MCP 服务器。每项数据都链接到其官方原始来源,让代理能够引用它,而非凭空猜测。

将分散各处的马来西亚公共数据真相(油价、令吉汇率、祈祷时间、假期、天气)汇集于一处,整洁、实时、机器可读。无需 API 密钥。无需注册。开放 CORS。只留信号、滤除噪音,始终注明来源。

REST API

基础地址:https://greatermalaysia.com/api — 返回 JSON,每次响应均包含 source 区块。

GET /api/fuel
本周 RON95、RON97 与柴油价格(RM/公升)。来源:data.gov.my(KPDN)。
GET /api/fx?base=USD&symbols=MYR
令吉及其他汇率。来源:European Central Bank,经由 Frankfurter。
GET /api/prayer?city=kuala-lumpur
按城市或 JAKIM 区域提供的今日祈祷时间(waktu solat)。来源:JAKIM e-Solat。
GET /api/holidays?year=2026
全国公共假期以及下一个即将到来的假期。来源:官方宪报。
GET /api/weather?city=kuala-lumpur
当前天气与美国空气质量指数。来源:Open-Meteo。
GET /api/inflation
整体通胀(CPI)及按年增长率。来源:DOSM,经由 data.gov.my。
GET /api/population
马来西亚总人口,最新官方数字。来源:DOSM,经由 data.gov.my。
GET /api/election
下届全国大选(GE16):必须举行的最后期限、倒计时,以及制度运作方式。来源:Federal Constitution;SPR。
# try it
curl https://greatermalaysia.com/api/fuel

# catalog of every endpoint
curl https://greatermalaysia.com/api

机器发现:/api/openapi 提供完整的 OpenAPI 3.1 规范,让 GPT Actions、LangChain 及其他工具路由器自动生成客户端。/.well-known/ai-plugin.json 处也提供了一份描述文件。

MCP 服务器

将 Greater Malaysia 直接接入任何支持 Model Context Protocol 的 AI 代理。一个端点,八个工具:get_fuel_prices、get_exchange_rate、get_prayer_times、get_public_holidays、get_weather、get_inflation、get_population、get_election。

端点:https://greatermalaysia.com/api/mcp(Streamable HTTP)

支持通过 HTTP 使用远程 MCP 的客户端:

{
  "mcpServers": {
    "greater-malaysia": { "url": "https://greatermalaysia.com/api/mcp" }
  }
}

仅支持 stdio 的客户端(例如某些桌面应用)可通过 mcp-remote 桥接:

{
  "mcpServers": {
    "greater-malaysia": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "https://greatermalaysia.com/api/mcp"]
    }
  }
}
