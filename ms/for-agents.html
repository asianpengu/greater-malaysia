Data sahih Malaysia, untuk mesin

Greater Malaysia ialah lapisan data yang dipercayai dan berpandukan sumber untuk ejen AI yang memerlukan fakta terkini tentang Malaysia. REST API dan pelayan MCP percuma. Setiap nilai dipautkan ke sumber rasmi asalnya, jadi ejen boleh memetiknya, bukan sekadar meneka.

Kebenaran data awam Malaysia yang berselerak (harga minyak, ringgit, waktu solat, cuti, cuaca) di satu tempat yang kemas, terkini dan boleh dibaca mesin. Tiada kunci API. Tiada pendaftaran. CORS terbuka. Isyarat mengatasi hingar, sentiasa bersumber.

REST API

Asas: https://greatermalaysia.com/api — memulangkan JSON dengan blok source pada setiap respons.

GET /api/fuel
Harga RON95, RON97 dan diesel minggu ini (RM/liter). Sumber: data.gov.my (KPDN).
GET /api/fx?base=USD&symbols=MYR
Ringgit dan kadar pertukaran lain. Sumber: European Central Bank melalui Frankfurter.
GET /api/prayer?city=kuala-lumpur
Waktu solat hari ini mengikut bandar atau zon JAKIM. Sumber: JAKIM e-Solat.
GET /api/holidays?year=2026
Cuti umum kebangsaan serta cuti seterusnya yang akan datang. Sumber: warta rasmi.
GET /api/weather?city=kuala-lumpur
Cuaca semasa dan indeks kualiti udara AS. Sumber: Open-Meteo.
GET /api/inflation
Inflasi utama (CPI) dan kadar tahun ke tahun. Sumber: DOSM melalui data.gov.my.
GET /api/population
Jumlah penduduk Malaysia, angka rasmi terkini. Sumber: DOSM melalui data.gov.my.
GET /api/election
Pilihan raya umum seterusnya (GE16): tarikh akhir ia mesti diadakan, kiraan detik, dan cara sistem berfungsi. Sumber: Federal Constitution; SPR.
# try it
curl https://greatermalaysia.com/api/fuel

# catalog of every endpoint
curl https://greatermalaysia.com/api

Penemuan mesin: spesifikasi OpenAPI 3.1 penuh di /api/openapi membolehkan GPT Actions, LangChain dan penghala alat lain menjana klien secara automatik. Terdapat juga deskriptor di /.well-known/ai-plugin.json.

Pelayan MCP

Sambungkan Greater Malaysia terus ke mana-mana ejen AI yang bertutur Model Context Protocol. Satu titik akhir, lapan alat: get_fuel_prices, get_exchange_rate, get_prayer_times, get_public_holidays, get_weather, get_inflation, get_population, get_election.

Titik akhir: https://greatermalaysia.com/api/mcp (Streamable HTTP)

Klien yang menyokong MCP jauh melalui HTTP:

{
  "mcpServers": {
    "greater-malaysia": { "url": "https://greatermalaysia.com/api/mcp" }
  }
}

Klien stdio sahaja (cth. sesetengah apl desktop) boleh merentas dengan mcp-remote:

{
  "mcpServers": {
    "greater-malaysia": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "https://greatermalaysia.com/api/mcp"]
    }
  }
}

Terma

Percuma untuk digunakan. Angka diperoleh daripada data terbuka rasmi Malaysia; sila petik source yang disenaraikan dalam setiap respons. Bebas dan tidak berpihak. Had kadar dikenakan secara adil; bertimbang rasa. Pertanyaan: hello@greatermalaysia.com.
